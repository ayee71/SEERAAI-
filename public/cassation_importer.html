Faayila seeraa galchi → barruu guutuu eegi → murtiiwwan addaan baasi → damee seeraatiin ramadi → JSON / JavaScript buufadhu.

Local-first processing
Faayilli gara serverii hin ergamu. Browser kee keessatti qofa qophaa'a.

1. Faayila galchi

MULTI-FILE

Faayiloota tokkoo ol yeroo tokkotti filachuu dandeessa.

Hubachiisa barbaachisaa

  • Barruun PDF/DOCX keessaa baafame akkaataa faayila jalqabaa guutummaatti hin fakkaatu; garuu barruun baafame hin haqamu.
  • PDF suuraa/scanned yoo ta'e barruu baafamuu dhiisuu danda'a. OCR addaa barbaada.
  • Ramaddiin damee seeraa jechoota ijoo irratti hundaa'a; namaan sakatta'amee mirkanaa'uu qaba.
  • Ragaan hunda hin adda baane rawText keessatti ni kuufama; lakkoofsa ykn seera hin beekamne hin uumu.
