LICENSE AUDIT

You are working on the EXISTING SEERAAI legal AI application.

Your task is to perform Phase 1 of the SEERAAI Freedom, Open-Source and
Digital Rights Framework.

CRITICAL PRESERVATION REQUIREMENTS

1.  Do NOT create a new application.
2.  Do NOT replace the existing application.
3.  Do NOT delete or rename existing files.
4.  Do NOT modify existing Firebase configuration, Firestore rules,
    Firebase Storage, Authentication, or database collections.
5.  Do NOT change the existing Firebase project or Cloud Run service.
6.  Do NOT remove or replace Gemini or OpenAI integrations.
7.  Preserve all existing users, court documents, legal databases and

TASK 1 — SOFTWARE INVENTORY

Inspect and document:

-   package.json
-   package-lock.json
-   All direct and transitive dependencies
-   React and Vite packages
-   Firebase client and admin SDKs
-   Google GenAI SDK
-   OpenAI SDK and API integrations, if present
-   Backend services
-   Frontend components
-   Third-party libraries and utilities

TASK 2 — LICENSE COMPLIANCE

Identify the license of each dependency.

Classify licenses, including:

-   MIT
-   Apache-2.0
-   BSD
-   ISC
-   GPL-2.0
-   GPL-3.0
-   LGPL
-   AGPL
-   MPL
-   Proprietary
-   Unknown or unverified

Use SPDX identifiers where available.

Flag:

-   Unknown licenses
-   Potentially incompatible licenses
-   Missing copyright notices
-   Missing required attribution
-   Dependencies whose license obligations require further legal review

Do not assume that every GPL or AGPL package is automatically
incompatible. Assess the dependency’s actual use, integration and
distribution context.

TASK 3 — DATA OWNERSHIP AND PRIVACY AUDIT

Inspect the existing:

-   Firebase Authentication
-   Firestore
-   Firebase Storage
-   Firestore Security Rules
-   Institution-based RBAC
-   Court document management
-   Audit logging
-   User data access paths

Identify who can read, upload, modify, export and delete information.

Pay special attention to sensitive court records and institutional
access restrictions.

Do not recommend unrestricted deletion or sharing of judicial records.

TASK 4 — AI PROVIDER INDEPENDENCE

Inspect Gemini and OpenAI integration architecture.

Identify:

-   Model configuration
-   API key management
-   Backend-only environment variables
-   Model fallback mechanism
-   Provider-specific dependencies
-   Potential vendor lock-in

Do not expose API keys or secrets in the report.
